Werte eingeben und Berechnen wählen.

FORMEL

X = F₀ / √[(k − mω²)² + (cω)²]

Annahmen

Vorausgesetzt werden eine lineare Feder, viskose Dämpfung und eine direkte Kraft F₀ cos(ωt) auf einen Freiheitsgrad. Einschwingvorgänge aufgrund von Anfangsbedingungen werden nicht berücksichtigt. Bei c = 0 ist das Ergebnis die Amplitude der harmonischen Partikulärlösung; freie Bewegung klingt dabei nicht ab. Ungedämpfte Resonanz bei F₀ > 0 besitzt keine endliche stationäre Amplitude. Bei ω = 0 ergibt sich die statische Auslenkung F₀/k.

Die angezeigten Werte sind Gleitkommanäherungen. Bemessungssicherheitsfaktoren und nicht angegebene Fehlerbeiträge werden nicht berechnet.
